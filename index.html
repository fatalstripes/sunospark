For Ollama: Use exactly http://localhost:11434/v1 (or try 127.0.0.1).
Windows users (Ollama desktop app is very common):
The app runs a background server. Right-click its tray icon → Quit, then run in PowerShell:
$env:OLLAMA_ORIGINS="*"; ollama serve (leave window open).
Or set it permanently so the desktop app works without manual steps (see Test failure message for exact commands). Running on HTTPS: local http://localhost calls are blocked. Use the Download for Local AI button.
